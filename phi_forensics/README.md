# phi-forensics

A read-only toolkit for on-chain investigation of Polymarket wallets and markets, with a command line and a Model
Context Protocol (MCP) server that expose the same 21 tools. It lives in
[the repository of the investigations](https://github.com/searadacunha/POLYMARKET-HOME-OF-THE-INSIDERS) and reads their
archives. Standard library only, Python 3.11 or later, no dependency.

Each answer is JSON and carries its sources (how many HTTP and JSON-RPC answers were read, their SHA-256 digests, the
first of them) and a list of limits. Amounts are exact decimal strings in collateral units.

## Install

From a checkout of the repository:

```sh
python3 -m venv .venv
.venv/bin/pip install .
```

The wheel holds `phi_forensics`, its two data files and the two `monitoring` packages it imports (`phi_monitor`,
`livecollect`). The investigations, datasets and tests are not in it. `pip install` writes `build/` and
`phi_forensics.egg-info/` into the checkout; delete them afterwards or build from a copy.

Once `pyproject.toml` is on the default branch, pip can also install straight from GitHub. pip then clones the whole
repository (about 450 MB of history) to build a wheel of less than 200 KB:

```sh
pip install git+https://github.com/searadacunha/POLYMARKET-HOME-OF-THE-INSIDERS
```

Two kinds of tools:

- **Live tools** read the public Polymarket APIs (`data-api`, `gamma-api`, `clob`) and public Polygon nodes. They work
  from any directory and need network access.
- **Offline tools** read the published archives. They need a checkout: an installed package finds it only through
  `PHI_REPO_ROOT`, code run from the source tree finds it by itself. Without one they refuse with `this tool reads
  the published archives: it needs a checkout of the repository (set PHI_REPO_ROOT)`.

## Use

Command line. Every tool is a sub-command with the arguments of its MCP schema:

```sh
phi-forensics tools                                   # name, title and description of the 21 tools
phi-forensics server_status                           # version, hosts read, whether a checkout was found
PHI_REPO_ROOT=/path/to/checkout phi-forensics search_findings --level CONFIRMED --limit 3
phi-forensics investigate_market --help               # the arguments of one tool
```

`python3 -m phi_forensics` is the same command. The exit code is 1 when a tool reports an error.

MCP server over stdio, for an AI agent. It speaks the `initialize` handshake (protocol 2024-11-05 to 2025-11-25) and
the per-request form of 2026-07-28. Client configuration (Claude Code, Claude Desktop, Cursor) is in
[docs/mcp.md](https://github.com/searadacunha/POLYMARKET-HOME-OF-THE-INSIDERS/blob/main/docs/mcp.md):

```sh
phi-forensics-mcp
```

Python. Each tool is a plain function of a dict, the same one the server calls:

```python
from phi_forensics.mcp import server

tools = {tool.name: tool for tool in server.tools()}
answer = tools["search_findings"].handler({"level": "CONFIRMED", "limit": 3})
```

The modules underneath (`investigate`, `ledger`, `funding`, `cluster`, `evidence`, `market`, `compare`, `behaviour`,
`archive`) take a `sources.Sources` reader as first argument. Its HTTP and JSON-RPC transports are injectable
(`Sources(fetch=..., rpc=..., clock=...)`), which is how the tests run offline.

## Read-only

- No tool holds a key, signs, sends a transaction or places an order. The chain is read with `eth_blockNumber`,
  `eth_getBlockByNumber`, `eth_getLogs`, `eth_getTransactionReceipt`, `eth_getCode`, `eth_getTransactionCount` and
  `eth_call`.
- HTTP goes only to the three Polymarket hosts: `sources.Sources.get` refuses any other host.
- Nothing is written to disk. The one tool that runs code, `reproduce_check`, runs a named offline step of the committed
  workflow `.github/workflows/repository-integrity.yml` (read from `HEAD`, not from the working tree) and removes the
  `__pycache__` folders it created.
- Profile text, bios and images are never returned; free text from third parties is stripped of control characters
  and bounded.

## What the answers do not show

- A transfer shows that money moved between two addresses, not who controls them. An address shared by many wallets
  (an exchange, a bridge, a relayer) is reported and never counted as a link.
- No tool says that a wallet is an insider. Buying before a price move is compatible with public information, the
  trader's own analysis, hedging and chance. The frozen studies of this repository validated no detection rule; an
  archived alert is a flagged pattern, not a signal.
- A finding of the archives is shown as the repository published it, with its evidence level; the tool does not
  verify it again. `reproduce_check` does.

## Limits

- Live tools depend on public endpoints that rate-limit, change and sometimes fail. A failure is an error, never an
  empty answer.
- API amounts omit some fees and cannot place neg-risk conversions; `reconstruct_positions --exact` reads every amount
  from the chain and is slower.
- Long lists are cut to a stated number of rows (the `limit` argument where a tool has one, 500 at most) and give the total.
- The MCP server refuses a result larger than 400,000 bytes rather than cut it, and accepts 60 tool calls per minute.
- The MCP server serves stdio only, with no HTTP transport. It answers `resources/list` and `prompts/list` with
  empty lists.
- The seed list of service labels (`data/service_labels.json`) is short. An address in no list is classified by its
  behaviour on the chain, which is weaker evidence than a label.
