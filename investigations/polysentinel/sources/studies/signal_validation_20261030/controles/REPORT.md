# Contrôles avant gel

Trois graines déterministes, trois niveaux de montants, quatre délais : scores attendus0/1/2 obtenus dans les36 snapshots. Neuf exclusions par observed_at réel futur, neuf contrôles de suppression/frontières de temps, file et ex aequo, censure50000 et âge préfixe complet, rejet témoin externe périmé, rejet timestamp non fini. Les contrôles exécutent les mêmes helpers et le noyau, pas une population réaliste. Pas de puissance inférentielle ni taux de faux positifs. Les tests ne prouvent pas une réussite historique.

Les audits pré-gel ont fait corriger l'âge censuré, interdire une troncature non prise en charge par les retraits, vérifier l'égalité aux noms de règles du résumé antérieur, exporter toute la distribution des scores, et détecter le témoin externe périmé malgré le fail-open de l'utilitaire hérité. Le module hérité reste identique ; le caller vérifie strictement longueur, chaîne et témoin. Les variantes finales conservent tous les autres wallets (contrôle supplémentaire de préservation des pairs), et distinguent une paire disparue d'une paire évaluée à score0. Les contrôles initiaux sont conservés au registre avec leur convention60 ou58 ; passe finale59 selon nomenclature du plan.
