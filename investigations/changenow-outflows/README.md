# Reverse analysis of ChangeNOW payouts

Descriptive, exploratory and not frozen: count what ChangeNOW payout addresses pay, find fresh addresses that reach Polymarket, and compare with the 11 files and with controls.

**State:** Running in a parallel session at snapshot time: plan written, collection under way, no report.
