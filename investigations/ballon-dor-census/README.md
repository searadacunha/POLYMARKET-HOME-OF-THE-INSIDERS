# Census of the Ballon d'Or market family

Counter-investigation of the 2026 Ballon d'Or case, built to try to destroy each link: the tape of the whole market family gives a control population selected on having traded rather than on having won, published addresses are only leads, and the results of the other investigations are never evidence here. See `sources/PROTOCOL.md`.

**State:** Running in a parallel session at snapshot time. No report yet.

## Reproduce

Scripts in `sources/code/`. Large derived files and `raw/` are not published.
