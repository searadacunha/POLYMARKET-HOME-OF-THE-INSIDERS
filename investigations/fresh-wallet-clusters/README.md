# Fresh wallet clusters

No. On the markets this run actually read, fresh wallets that each commit at least $1,000 to the same outcome do not form groups whose private funding or private withdrawals exceed what chance and shared services already explain.

The only verified private-funding link in the sample is the Nobel Peace Prize 2025 market this repository had already published. The collector found it again. It was held out of the confirmatory denominator. A transfer is not a common owner, and it is not evidence that anyone held non-public information.
