# Publication copy of PolySentinel

Copy of the PolySentinel code prepared for publication, without data.

**State:** No PolySentinel repository exists on the GitHub account as of November 2, 2026: this copy is unpublished. All files match `polysentinel` except `polysentinel/service.py`.

## Reproduce

`python3 scripts/restore_duplicates.py --id polysentinel-public --dest <folder>`.

## Contents

Snapshot of November 2, 2026. `sources/` is a verbatim copy of the original working tree, mostly in French, with relative paths kept. `data_manifest.json` lists every original file, published or not, and why. `local_only_hashes.sha256.gz`, when present, holds the hashes of large unpublished sets.
