## Improvements introduced by this audit

- A new **offline, fail-closed G38 verifier** checks the unique proxy set, cohort time sequence, ledger sums, presence of open tokens, distinct deposit funding wallets, official USDC contracts, destination balance conservation and **individual** Polygon Relay order-to-recipient-transfer values. One on-chain credit cannot silently count for two orders merely because the aggregate matches.
- A synthetic negative-test suite checks mismatched legs, repeated order identifiers, missing settlement and one-micro-USDC discrepancies, while allowing legitimate duplicate amounts with distinct order identifiers.
- A read-only repository checker parses every tracked Python file to AST (with separately reported historical snapshot limitations) and scans public research/tooling files for **high-confidence** credential formats without printing secret contents. This supplements, but does not replace, the existing investigation import scanner.
- The research index and public-facing G38 text are reconciled to explicit tiers. Original evidence, raw recordings, frozen protocols, archived findings and independent cohorts are not silently rewritten.
